# Сургуулийн борлуулалтын цэг (POS) + Админ

Сургалтын албаны дүрэмт хувцас, ном, дэвтрийн борлуулалт. QPay-ээр төлбөр авч, хэмжээ тус бүрийн үлдэгдлийг автоматаар хөтөлнө. Аль ч сургууль `.env`-ээ өөрчлөөд ашиглаж болно.

## Эхлүүлэх

```bash
pnpm install          # эсвэл npm install
cp .env.example .env  # утгуудаа бөглөнө (MongoDB, QPay, S3, JWT)
npm run seed          # анхны админ, ангилал, бараа + эхний үлдэгдэл
npm run dev           # http://localhost:3000  ·  админ: /admin
```

Seed-ийн админ: `admin@school.mn` / `ChangeMe123` (`SEED_ADMIN_EMAIL`, `SEED_ADMIN_PASSWORD`-оор өөрчилж болно). Нэвтэрсэн даруйдаа нууц үгээ солино уу. Солих хүртэл хянах самбарт улаан сануулга гарна.

`npm run seed` дахин ажиллуулахад аюулгүй: байгаа админ, ангилал, барааг (slug-аар) хөндөхгүй, зөвхөн дутууг нэмнэ. Зөвхөн нэг хэсэг: `npm run seed -- admin | categories | products`.

## Бүтэц

| Хэсэг | Хаана |
|---|---|
| Борлуулалтын цэг | `/` — бараа DB-ээс уншина, дууссан хэмжээ сонгогдохгүй, үлдэгдлээс илүү сагслахгүй |
| Хянах самбар | `/admin` — өнөөдөр/сарын орлого, 14 хоногийн график, ангиллаар, их зарагдсан бараа/хэмжээ, дуусч буй бараа |
| Захиалга | `/admin/orders` — шүүлт, CSV татах, төлбөр дахин шалгах, цуцлах, буцаалт (үлдэгдэлд буцаана) |
| Бараа | `/admin/products` — нэр, үнэ, зураг (S3), хэмжээ тус бүрийн үлдэгдэл, нуух/гаргах |
| Агуулах | `/admin/inventory` — бүх барааг нэг хүснэгтээр орлого авах / тооллого / хорогдол, хөдөлгөөний түүх |
| Ангилал | `/admin/categories` — Хувцас, Ном, Дэвтэр…; «хэмжээтэй» ангилалд түгээмэл хэмжээнүүд |
| Админууд | `/admin/users` |

**Үлдэгдлийн дүрэм:** нэхэмжлэх үүсгэхэд үлдэгдэл шалгана; QPay төлбөр баталгаажих үед (кассын «Төлбөр шалгах», QPay callback, эсвэл админ) нэг л удаа хасна. Өөрчлөлт бүр `stock_movements`-д хэн, хэзээ, хэдээр гэдэг нь бүртгэгдэнэ.

QPay тохируулаагүй бол туршилтын горимд ажиллана (төлбөр 5 секундэд автоматаар «төлөгдөнө») — хянах самбарт сануулга гарна.

## Deploy

- `.env`-ийн бүх утгыг хостинг дээр тохируулна. JWT түлхүүрүүдийг `openssl rand -hex 32`-оор шинээр үүсгэнэ.
- QPay callback нь `https://<домэйн>/api/qpay/callback` (эсвэл `QPAY_CALLBACK_URL`). Reverse proxy ард бол `x-forwarded-host`/`x-forwarded-proto` дамжуулна.
- MongoDB Atlas бол серверийн IP-г Network Access-д нэмнэ.
